# セルフレビューの方針

セルフレビューは、**作成した成果物そのものに問題がないか確認する工程**である。成果物がタスクの完了条件を満たしているかの照合は、次の検証工程で行う。

## 確認する観点

成果物の種類と用途に応じて、適切な観点を選ぶ。

- 明らかな誤り
- 抜け漏れ
- 内容や構成の不整合
- 読みやすさ、理解しやすさ
- 表現や構成の一貫性
- 不要な重複
- その他、利用に影響する品質上の問題

## 進め方

作成した実物を読み、見る、動かすなど、その成果物に合った方法で確認する。必要に応じてタスクIDと参照先を添え、どのタスクで作成した成果物のどの部分を確認したか追跡できるようにする。

問題が見つかったら修正し、修正箇所と影響を受ける部分を再確認する。確認した観点と重要な修正点を簡潔に残し、未解決の問題を隠さない。

セルフレビューで問題が見つからなかったことだけで、タスクの完了条件を満たしたと判断しない。レビュー後の実物を対象に、別途検証する。
