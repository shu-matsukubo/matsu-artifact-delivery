# セルフレビューの方針

セルフレビューは、各担当の `artifact-worker` が**作成した成果物そのものに問題がないか確認する工程**である。成果物がタスクの完了条件を満たしているかの照合は、親が次の検証工程で実物を確認して行う。

今回の生成範囲の各作業タスクを処理するフローの一部として実施し、セルフレビュー専用のタスクは作らない。確認結果・修正・再確認は、作成を担当した元のタスクIDに対応付ける。複数タスクをまとめて確認する場合も同じ対応を保つ。後続 Plugin が行う更新・公開などの処理や、その結果の検証はセルフレビューの対象にしない。

## 確認する観点

成果物の種類と用途に応じて、適切な観点を選ぶ。

- 明らかな誤り
- 抜け漏れ
- 内容や構成の不整合
- 読みやすさ、理解しやすさ
- 表現や構成の一貫性
- 不要な重複
- その他、利用に影響する品質上の問題

## 進め方

作成した実物を読み、見る、動かすなど、その成果物に合った方法で確認する。必要に応じてタスクIDと参照先を添え、どのタスクで作成した成果物のどの部分を確認したか追跡できるようにする。

問題が見つかったら承認済みの担当範囲内で修正し、修正箇所と影響を受ける部分を再確認する。担当外の問題は親へ報告する。確認した観点と重要な修正点を簡潔に残し、未解決の問題を隠さない。

レビュー後は、タスクIDごとに成果物の実物または親がアクセスできる参照先・該当部分、確認した観点・方法・結果、重要な修正点、未解決の問題・確認できなかった点を親へ返す。ファイルの参照先は絶対パスで示す。

セルフレビューで問題が見つからなかったことだけで、タスクの完了条件を満たしたと判断しない。親がレビュー後の実物を対象に、別途検証する。
