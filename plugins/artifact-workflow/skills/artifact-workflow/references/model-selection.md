# モデル選定・起動・記録

Worker と Reviewer の親は、起動ごとにタスク特性、役割、実行環境で利用可能なモデルを確認し、必要な推論強度を選ぶ。選定は確認済みの能力情報など根拠のある情報だけで比較し、モデル名から性能差を推測したり固定順位を設けたりしない。

起動時に実際に提示された委任 API の schema と制約を確認し、選択したモデルと推論強度を対応する引数へ指定する。現在の `collaboration.spawn_agent` で model または reasoning_effort を上書きするときは `fork_turns: "none"` を指定し、暗黙に引き継がれない必要な依頼・文脈・資料を新しい context へ明示的に渡す。schema が異なる環境ではその実仕様に従う。

モデル情報が得られない、候補が利用可能だと確認できない、または起動手段が指定を受け付けない場合は明示指定を省略し、環境の既定・継承へフォールバックする。その理由と選択根拠を親の既存記録へ残す。起動結果が実効モデルを示さない場合、選択した要求値だけを記録し、実効値は未確認とする。指定省略だけで AI による選定成功や実効値を確認済みと扱わない。
