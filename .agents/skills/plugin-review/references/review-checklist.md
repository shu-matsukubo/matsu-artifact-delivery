# レビュー観点と仕様

## 基準となる仕様

- [プラグイン仕様](https://agent-plugins.org/specification): プラグインの構成、マニフェスト、配布単位を確認する。
- [スキル仕様](https://agentskills.io/specification): スキルのメタデータ、ファイル構成、参照・素材の配置を確認する。
- [Codex スキルガイド](https://developers.openai.com/codex/skills): リポジトリ用スキルの配置と読み込みを確認する。

## 確認項目

- **要件と責務**: 差分が依頼された挙動を実現し、プラグイン・スキル・エージェント・MCP の役割が重ならない。
- **仕様と参照**: 規格に沿った構成であり、マニフェスト、生成設定、参照先が正本と配布物の両方で整合する。
- **挙動と試験**: 変更・維持する契約、失敗時の扱い、該当する単体テストと E2E テストが確認されている。
- **説明と安全性**: 利用者向け・開発者向けの説明が現行実装と一致し、権限や外部入力、秘密情報の扱いに問題がない。

関係する項目だけを確認し、チェック項目を無関係な差分に一律適用しない。好みや一般的な改善案だけは不具合として報告しない。
