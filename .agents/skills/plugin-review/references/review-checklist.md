# Plugin レビュー観点

レビュー対象の差分に関係する項目だけ確認する。

- **仕様と責務**: Plugin、Skill、Agent、MCP が規格と既存の責務境界に一致する。
- **Skill の契約**: `name`・`description` が用途と起動条件を示し、手順・制約・出力が一貫する。
- **参照と配布**: manifest、ローカル参照、生成物、配布物の参照先が存在し、パッケージ内から解決する。
- **正本と同期**: portable manifest と Codex 互換設定の同期が保たれ、生成物を直接修正していない。
- **失敗時の扱い**: 欠落、不正入力、権限不足、MCP エラーを誤って成功として扱わない。
- **安全性**: 操作範囲、権限、外部入力、秘密情報の扱いに問題がない。
- **検証**: 変更した契約を確認する試験があり、文書や参照資料が現行実装に一致する。

重大度は実際の影響に合わせる。指摘は重要度順に、対象ファイルと行、再現条件、影響を記す。好みや一般的な改善案だけは不具合として報告しない。
