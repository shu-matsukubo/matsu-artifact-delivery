# 対象 Issue の確認・選定

- Issue が指定された場合は対象リポジトリの Open Issue であることを確認し、依頼範囲を扱う。指定 Issue に `AI処理可能` ラベルやプラグイン変更への限定は要求しない。要件・依存関係から実装可能性を判断する。
- 具体的な変更依頼では Issue を選定しない。Issue 未指定なら、依頼された変更を Workflow の実装・レビュー手順で進める。

- 対象 Issue の選定を明示的に依頼された場合は、`AI処理可能` ラベル付きの Open Issue を取得する。プラグインの新規作成・修正に該当する候補だけを対象とし、インフラ、CI、リポジトリ文書のみの Issue は対象外とする。

- 候補に関連付けられた実装 PR を、ブランチ名にかかわらず確認する。Open の実装 PR がある候補と、default branch へ merge 済みの実装 PR があり人間の Close 待ちの候補は除外する。指定 Issue が該当する場合は既存 PR を報告して終了する。

- 残る候補から内容、優先度、依存関係、実装可能性を判断して一件選ぶ。固定の priority ラベルは要求しない。対象 Issue がない場合は終了する。
