# 対象 Issue の確認・選定

Issue が指定されている場合は、対象リポジトリの Open Issue であることを確認し、依頼された範囲を扱う。指定 Issue に `AI処理可能` ラベルやプラグイン変更への限定は要求しない。要件・依存関係から実装できるか判断する。

Issue が未指定でも、具体的な変更依頼では対象 Issue を選定しない。依頼された変更を Workflow の実装・レビュー手順で進める。

対象 Issue の選定を依頼された場合、または定期 Issue 処理から起動された場合は、選択した手段で `AI処理可能` ラベル付きの Open Issue を取得し、プラグインの新規作成・修正に該当する候補だけを対象にする。インフラ、CI、リポジトリ文書のみの Issue は対象外とする。

Issue を扱う場合は、候補に関連付けられた実装 PR を、ブランチ名にかかわらず確認する。Open の実装 PR がある候補と、default branch へ merge 済みの実装 PR があり人間の Close 待ちの候補は除外する。指定 Issue がこれに該当すれば、既存 PR を報告して終了する。

選定時は残る候補の内容、優先度、依存関係、実装可能性を判断して一件選ぶ。固定の priority ラベルは要求しない。対象 Issue がない場合は終了する。
