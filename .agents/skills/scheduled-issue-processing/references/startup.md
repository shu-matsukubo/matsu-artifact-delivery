# 起動条件

Codex のスケジューラ / オートメーションから同一スレッドで繰り返し実行する。スケジューラから Skill 名を直接指定して起動する。通常の Issue 対応や一般的な開発作業では使用しない。

人間が普段操作するリポジトリとは別の、スケジューラ専用 clone / 作業ディレクトリを使う。

GitHub Plugin の利用可否と、対象リポジトリ・Issue・PR・ブランチの読み取り、ブランチへの変更反映、PR 作成に必要な read/write capability と権限を確認する。GitHub Plugin が使えない、または必要な capability が不足している場合は、処理を開始せず、Plugin の導入または権限設定が必要と報告して終了する。

全段階で GitHub 上の状態を確認・更新できない場合は、git、`gh`、ブラウザー等へフォールバックせず停止する。Plugin の導入または権限設定が必要であることを報告する。

独自の状態ファイルやチェックポイントファイル（リポジトリ外、`.codex/runtime`、Issue 処理専用の JSON / YAML、前回ステップ番号等）は作成・永続化しない。状態管理用のラベルは追加しない。実行結果や中断内容は同一スレッドで報告する。
